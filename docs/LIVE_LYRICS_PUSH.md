# Live Lyrics push experiment

`POST /api/live-lyrics` relays fresh ActivityKit content from an App Attest authenticated Lyra session. It supports the Debug app `com.hongkuntian.musicromanization`; the push topic is fixed on the server. This tests APNs delivery while Lyra owns playback. It cannot observe an external Apple Music pause, seek, or song change after Lyra is suspended.

Provision `LYRA_APNS_TEAM_ID`, `LYRA_APNS_KEY_ID`, and sensitive `LYRA_APNS_PRIVATE_KEY` in production Vercel server environment variables. The private key must be a P-256 APNs key. The iOS provisioning profile must include Push Notifications and production App Attest; its `aps-environment` determines the sandbox or production APNs endpoint. Never put the private key in the app or repository. Apply migrations `022-live-lyrics-push.sql`, `023-live-lyrics-runtime.sql`, and `024-live-lyrics-cleanup.sql` through `migrateLibrary` with the owner connection before deployment. Migration 023 grants the existing restricted `lyra_runtime_v1` login SELECT, INSERT, UPDATE and DELETE on only the two relay tables. Migration 024 indexes rate-window expiry for bounded cleanup. Production builds verify the migration receipt; they do not need owner credentials. When provisioning a different runtime role, grant those same operations explicitly and verify its access before a phone test.

The app sends `{activityID, token, environment, reason, state}`. `state` is the default Swift Codable ContentState: `observedAt` is seconds since 2001, not an ISO string. Requests older than eight seconds are rejected. APNs expiry is zero and stale-date is the observation time plus eight seconds. Visible cue/page changes use priority 10; four-second freshness heartbeats use priority 5. Apple may delay or throttle delivery, so acceptance by APNs is not proof of a rendered card update.

The independent user quota is 120 requests per minute and includes failed attempts. A per-activity receipt serializes pushes; sequence numbers and integer Unix timestamps must advance. A same-second change returns 429 with Retry-After 1 so the app coalesces the latest observation. On transport failure the app uses its local update path. Invalid tokens await rotation; stale observations never renew the card.

The database retains only owner, activity ID, token digest, last sequence/timestamp and a 30-minute expiry. It does not retain lyrics or raw push tokens. The request state and token exist only during relay execution. After a successful update commits, a warm database pool attempts cleanup at most once a minute, removing at most 1,000 expired receipts and 1,000 rate windows older than a day. Cold pools may also sweep. Indexed selection skips locked rows; cleanup uses its own transaction with a 500-ms statement timeout and a 100-ms lock timeout. A cleanup failure emits only `live_lyrics_cleanup_failed` and does not fail the delivered update. Failed maintenance attempts are also throttled. No idle database is kept awake solely for housekeeping. Current activity receipt expiry is checked during its upsert, so restarting an expired activity does not depend on a global sweep. Diagnostics contain delivery events and sequence numbers without the private key, tokens, lyrics, or account credentials.

For a reproducible local comparison, run `node scripts/benchmark-live-lyrics.mjs --users 1000 --samples 200` (or `--users 10000`). It seeds one hour of synthetic quota windows per user, compares the retained baseline with indexing alone and bounded maintenance, and records SQL counts, local timings, process CPU, and cleanup query plans. It uses PGlite with a fake APNs sender; it is not production capacity evidence or a measurement of Vercel billed CPU. Keep real APNs request cadence and refresh behavior unchanged until physical evidence supports a different cadence.

Verify sustained physical-phone playback in unlocked Notification Center without a debugger, plus pause, seek and track transitions. Compare system pixels against observations; `push-accepted` and ActivityKit `contentUpdates` alone do not establish rendering or exact lyric timing. Keep the experiment off by default until that evidence supports enabling it.
