# Lyra dashboard

Private, read-only translation operations on Next.js, TypeScript and Neon.

See [the dashboard guide](../docs/DASHBOARD.md) for setup, access protection, cost semantics and delivery.

Use Node 24, then `npm ci` and `npm run dev`. Local development uses synthetic fixtures. `npm test` verifies queries and permissions; `npm run test:e2e` checks desktop and mobile journeys after `npm run build`.
